# Hey, I’m Saif.
A new, separate personal portfolio. The existing midnight portfolio is untouched.

## Color demos
- `?theme=cream`: warm cream #F5F4EB, ink #22231C, lime #D7FA54.
- `?theme=yellow`: white #FFFFFF, near-black #141414, yellow #FFD400.
Both use the same markup, copy, assets, layout and animation code.

## Booking
Set `bookingUrl` in `config.js` to the verified Calendly event URL. Until configured, both buttons open an accessible dialog explaining that the calendar is being set up and linking to Saif’s LinkedIn. No time slot or booking confirmation is fabricated.

## Run
Serve this folder with any static HTTP server. GitHub Pages: deploy main / root.
